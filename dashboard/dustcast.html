Read this before quoting a number

  • The 500 MW national total is STEG's (end-June 2026). Its split across governorates is ours, allocated by population because Tunisia publishes no PV registry — that probably over-weights Tunis and under-weights the Sahel.
  • The fleet is simulated: 9 sampled rooftops per governorate with plausible tilt, azimuth and capacity. The upscaling method is the real one AEMO and Sheffield Solar use on actual registries.
  • The model is trained on 17 years of Australian desert PV (DKASC Alice Springs) because no Tunisian generation data is public. Residual learning transfers loss mechanisms, not a power curve — but it is still a transfer assumption.
  • The dust correction is fitted where Tunisia is dustier than the training site ever gets: DKASC's 95th-percentile AOD is 0.175 and Tunisia currently sits near 0.30. Those values are extrapolated.
  • The band is calibrated against forecast irradiance, not measured. An earlier version calibrated on measured weather and was 21× too narrow for a deployment driven by an NWP — the calibration set has to look like deployment.
  • Band coverage is verified at 90.4% on Australian data. There is no measured Tunisian output to verify it against here.
